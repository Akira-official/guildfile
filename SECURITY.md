# Security Policy

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

The guildfile team and community take the security of Discord servers seriously.

If you discover a security vulnerability (such as permission escalation, token disclosure, or AutoMod filter bypass), please do **NOT** open a public issue.

Instead, please responsibly disclose it by emailing:
**security@vyoma.dev** or messaging **Akira** directly on Discord.

### What to include:
- Description of the vulnerability.
- Steps to reproduce or proof-of-concept blueprint.
- Potential impact on servers or members.

We will review your submission and respond within **24 hours**.
